# 구현 요청 (claude-1): 수면 기록 상세 평균이 기간 칩을 따르지 않음
실기기: 30일/90일 모두 평균 "4시간 19분". DB 직접 계산 결과 30일 평균 262.4분(4시간 22분), 90일 259.2분(4시간 19분). → 30일 선택 시에도 90일 데이터로 평균을 계산하는 것으로 보임.
- 수면 기록 상세에서 평균·최장·최단·목록이 **선택한 기간(오늘 포함 N일)** 의 SleepDay만 쓰도록 수정. 그래프와 같은 데이터 소스를 쓰게.
- 같은 문제가 걸음 상세(평균·최고·목표 달성일), 체중/체성분 상세 통계에도 있는지 확인하고 있으면 같이 수정 (StepsDetail은 claude-2가 이전에 수정했지만 지금은 작업 중 아님, 수정 가능).
- 원인 한 줄을 tasks/fix-sleep-avg-done.md 에. 빌드 assembleDebug (JAVA_HOME = Android Studio jbr).
